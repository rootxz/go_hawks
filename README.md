# 🏈 시애틀 시호크스 (Seattle Seahawks) 주요 선수 가이드 
NFL과 미식축구를 처음 접하는 친구나 입문자에게 **시애틀 시호크스(Seattle Seahawks)** 의 포지션별 핵심 선수들을 쉽고 직관적으로 소개하기 위해 제작된 인터랙티브 웹 가이드입니다. 
선수들의 공식 프로필 사진, 등번호, 영문/한국어 발음, 포지션 명칭, 그리고 초보자 눈높이에 맞춘 역할 설명을 한눈에 확인할 수 있습니다.


## ✨ 주요 기능 (Key Features)

1. **포지션 및 유닛별 맞춤 분류**
   * **공격팀(Offense)**, **수비팀(Defense)**, **스페셜팀(Special Teams)**으로 선수단을 구분하여 미식축구의 교대 시스템을 자연스럽게 이해할 수 있도록 돕습니다.
   * 복수 인원이 투입되는 주요 포지션의 선수들과 핵심 스페셜리스트 정보를 함께 제공합니다.

2. **표 보기(Table) & 카드 보기(Card) 모드 전환**
   * **표 보기**: 사진, 선수명(한국어 발음), 등번호, 포지션, 핵심 역할을 한 줄로 깔끔하게 비교할 수 있습니다.
   * **카드 보기**: 모바일 환경이나 시각적인 프로필 확인에 최적화된 그리드 카드로 선수들을 둘러볼 수 있습니다.

3. **공식 프로필 사진 및 폴백(Fallback) 처리**
   * 시애틀 시호크스 공식 로스터 기준의 프로필 사진을 표시하며, 클릭 시 사진을 크게 확대해 볼 수 있습니다.
   * 네트워크 오류 등으로 이미지 로드가 실패할 경우, 시호크스 테마 컬러(네이비 & 액션 그린) 기반의 등번호·이니셜 아바타가 자동으로 대체 표시됩니다.

4. **실시간 검색 및 필터링**
   * 선수 이름(영문/한국어), 등번호(예: `14`, `#21`), 포지션 약어(`QB`, `CB`), 한국어 포지션명(`쿼터백`, `코너백`) 등으로 원하는 선수를 즉시 찾을 수 있습니다.
   

## 📋 포지션 구성

| 구분 | 수록 포지션 (약어) | 한국어 명칭 |
| :--- | :--- | :--- |
| **⚔️ 공격팀 (Offense)** | `QB`, `RB`, `WR`, `TE`, `OT`, `G`, `C` | 쿼터백, 러닝백, 와이드 리시버, 타이트 엔드, 오펜시브 태클, 오펜시브 가드, 센터 |
| **🛡️ 수비팀 (Defense)** | `DE / DT`, `NT`, `OLB`, `ILB`, `CB`, `S` | 디펜시브 엔드/태클, 노즈 태클, 아웃사이드/인사이드 라인배커, 코너백, 세이프티 |
| **🎯 스페셜팀 (Special Teams)** | `K`, `P / H`, `LS`, `KR / PR` | 키커, 펀터/홀더, 롱 스내퍼, 킥/펀트 리터너 |


## 📌 참고 사항
* 인터넷 연결이 되어 있어야 Tailwind CSS 스타일시트, 웹 폰트, 그리고 선수들의 공식 프로필 이미지가 정상적으로 불러와집니다.
* 로스터 변동이나 등번호 변경 시 HTML 파일 하단 `<script>` 내부의 선수 데이터 배열에서 손쉽게 정보를 수정하거나 추가할 수 있습니다.
